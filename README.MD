# findCD

指定フォルダ直下のサブフォルダを検索し、あふｗ（`AFXW.EXE`）の左／右ウィンドウで開くWindows用ユーティリティです。フォルダが多い場所から目的のフォルダへ素早く移動できます。

黒基調のコンパクトな画面で検索・選択でき、複数語のAND検索に対応します。コマンドライン版については[cdafのREADME](cdaf/README.MD)を参照してください。

## 動作環境

Windows x64、あふｗ（`AFXW.EXE`）。

## 概要

<img src="findCD/assets/findCD.png" alt="findCDのアプリアイコン" width="64" height="64">

黒基調のコンパクトなウィンドウで検索・選択するアプリです。入力画面には検索欄のみを表示し、ウィンドウとダイアログは画面中央に表示します。

## 起動方法

```text
findCD.exe [検索先パス] [-afxw "AFXW.EXEのパス"]
```

例:

```text
findCD.exe
findCD.exe "D:\Work"
findCD.exe "D:\Work" -afxw "C:\Bin\afx\AFXW.EXE"
```

## 検索と選択

- パス省略時は起動時のカレントディレクトリを検索します。
- 検索先直下のサブフォルダ名を、大文字・小文字を区別せず部分一致検索します。スペース区切りで複数語を指定するとAND検索になります。
- 起動時は、あふのアクティブなファイル窓に合わせてL／Rを自動選択します。取得できない場合は保存済みの設定を使い、設定もなければLになります。
- Ctrl+L／Ctrl+Rであふの移動先を切り替えます。この操作では移動を実行せず、設定のみ変更・保存します。
- 結果リストでは←キーでL、→キーでRへ切り替え・保存できます。この操作でも移動は実行しません。入力欄の←／→キーは文字カーソルの移動に使います。
- 起動時にあふのアクティブ側を取得できた場合、L／Rボタンは非表示になります。取得できなかった場合は結果リストに表示し、押すとその側を保存して選択中のフォルダへ即移動し、終了します。
- Enterで検索します。結果が11件以上なら「多すぎ」、0件なら「フォルダが見つかりません」と表示し、入力に戻ります。
- 結果は名前順で最大10件表示します。上下キーで選んでEnter、または項目をシングルクリックすると、あふの指定側を移動して終了します。
- 数字キー1～9で対応する候補を選べます。0は10件目です。テンキーにも対応します。
- Escape、またはウィンドウの閉じるボタンでキャンセルします。

検索文字が空の場合、Enterを押しても検索しません。候補が1件でも結果リストを表示し、選択を待ちます。

## AFXW.EXEと設定の保存

AFXW.EXEは`-afxw`の指定、保存済みパス、`findCD.exe`と同じフォルダの順に確認します。見つからなければファイル選択ダイアログを表示します。明示的に指定したパスが無効な場合はエラーを表示します。

AFXW.EXEのパスとL／R設定は、ユーザーごとに`HKEY_CURRENT_USER\Software\bry-ful\findCD`へ保存します。保存先のAFXW.EXEを移動した場合、`-afxw`で新しいパスを指定できます。

アクティブなファイル窓の自動取得には、あふのオートメーションサーバの登録が必要です。あふの設定画面の「about」タブにある「登録」から設定できます。詳しくはあふ付属の`AFXWAMS.TXT`を参照してください。未登録の場合も、保存済みのL／R設定で利用できます。

## あふファイラーから使う例

この例では、`AFXW.EXE`と同じフォルダに`findCD.exe`を配置します。

1. メニューファイルを作成します。ここでは`Menu.txt`という名前にします。詳しくはあふ付属の`AFXWCFG.TXT`を参照してください。

   **Menu.txt**

   ```text
   afx F's Tools
   "cdaf"  "$V"afx"\findCD.exe"  "$P"
   ```

2. メニューをキーバインドに登録します。`AFXW.KEY`に次の設定を記述します。既存の設定がある場合は、該当するセクションへ必要な行を追加・変更してください。

   **AFXW.KEY**

   ```ini
   [KEYCUST]
   ON=1

   [NORMAL]

   K0000="0221&Menu $V"afx"\Menu.txt"

   [GVIEW]


   [TVIEW]
   ```

この例では、`]`キーに`Menu.txt`を登録しています。メニューから「cdaf」を選ぶと、`$P`で渡したフォルダを検索先としてfindCDが起動します。キーバインドの詳細はあふ付属の`AFXWKEY.TXT`を参照してください。
