# fdList

あふｗの操作側フォルダにあるディレクトリを検索して移動する、Windows x64 用のユーティリティです。

あふｗを1つ起動し、設定画面の「about」からオートメーションサーバを登録してから、`fdList.exe` を起動してください。

- Filter に入力すると、ディレクトリ名を大文字・小文字を区別せず部分一致で絞り込みます。空白で区切った語は AND 検索になります。
- 上下キーで一覧のアクティブ項目を移動します。Filter 入力中もキーボードフォーカスは入力欄に維持します。
- Enter でフォーカス項目のディレクトリへあふｗの操作側を移動し、あふｗをアクティブにして終了します。
- 項目のダブルクリックでも Enter と同じ移動処理を実行します。
- Escape で終了します。

マーク・チェック選択・表示種別の切り替え機能はありません。黒基調の画面で、通常の実在フォルダ直下のディレクトリだけを表示します。

起動時は起動元の画面の作業領域中央に表示します。終了時の通常サイズと最大化状態を `HKEY_CURRENT_USER\Software\bry-ful\fdList` に保存し、次回起動時に復元します。最小化状態で終了しても、次回は通常表示または最大化で開きます。検索履歴は保存しません。

あふｗ未起動、複数起動、COM接続失敗、読み込み失敗、操作側やパスの変化、移動失敗などの場合はエラーダイアログを表示します。
