# cdaf / findCD

指定フォルダ直下のサブフォルダを検索し、あふｗ（`AFXW.EXE`）の左／右ウィンドウで開くWindows用ユーティリティです。フォルダが多い場所から目的のフォルダへ素早く移動できます。

- **cdaf**：コンソールから検索・番号選択するコマンドライン版。
- **findCD**：黒基調のコンパクトな画面で検索・選択するWindowsアプリ版。複数語のAND検索に対応。

## 動作環境

Windows x64、あふｗ（`AFXW.EXE`）。

## cdaf（コマンドライン版）

- 検索は指定ディレクトリの直下サブフォルダのみ（再帰しません）。
- 大文字・小文字を区別せず部分一致検索。
- 最大 9 件まで表示。10 件以上検出すると "多すぎ" と表示して終了。
- 一覧から番号（1～9）を押すと、`cdaf.def` で指定したファイラー、または実行ファイルと同じフォルダの `AFXW.EXE` を起動して該当フォルダを左右どちらかのウインドウで開く。

### 使い方

- `-l` / `-L` / `/l` / `/L` : AFXW の左ウインドウを指定
- `-r` / `-R` / `/r` / `/R` : AFXW の右ウインドウを指定

例:

- `cdaf -l` （検索文字列を対話入力）
- `cdaf -r abc` （カレント直下で "abc" を含むフォルダを検索）
- `cdaf -l abc D:\Work` （`D:\Work` の直下を検索）

実行時は候補一覧が表示され、`1`～`9` を押すと該当フォルダをファイラーで開きます。`0` または `Esc` で終了。
候補が1件の場合は選択を待たずに移動します。検索先パスを省略した場合はカレントディレクトリを検索します。

### Menu.txt での使い方
Afxのメニュー指定でこんな感じに指定しておくと便利です。
```
"cdaf L" "C:\Bin\afx\cdaf" -l
"cdaf R" "C:\Bin\afx\cdaf" -r
```

### `cdaf.def` の仕様

実行ファイルと同じディレクトリに `cdaf.def` を置くと、1 行目で使用するファイラー実行ファイルのパスを指定できます。

- UTF-8（BOM 可）または ANSI に対応。
- 行頭末尾の空白・改行・引用符は除去されます。
- 指定が無い、または無効な場合は同じフォルダの`AFXW.EXE` を探します。

### トラブルシューティング

- ファイラーが見つからない／起動できない場合は `cdaf.def` を確認するか、`afw.exe` / `AFXW.EXE` を `cdaf.exe` と同じフォルダへ配置してください。


## findCD（Windowsアプリ版）

<img src="findCD/assets/findCD.png" alt="findCDのアプリアイコン" width="64" height="64">

黒基調のコンパクトなウィンドウで検索・選択するアプリです。入力画面には検索欄のみを表示し、ウィンドウとダイアログは画面中央に表示します。

### 起動方法

```text
findCD.exe [検索先パス] [-afxw "AFXW.EXEのパス"]
```

例:

```text
findCD.exe
findCD.exe "D:\Work"
findCD.exe "D:\Work" -afxw "C:\Bin\afx\AFXW.EXE"
```

### 検索と選択

- パス省略時は起動時のカレントディレクトリを検索します。
- 検索先直下のサブフォルダ名を、大文字・小文字を区別せず部分一致検索します。スペース区切りで複数語を指定するとAND検索になります。
- Ctrl+L／Ctrl+Rであふの移動先を切り替えます。この操作では移動を実行せず、設定のみ変更します。選択は次回も引き継ぎます。
- 結果リストでは←キーでL、→キーでRへ切り替え・保存できます。この操作でも移動は実行しません。入力欄の←／→キーは文字カーソルの移動に使います。
- L／Rボタンは結果リストに表示します。押すとその側を保存し、選択中のフォルダへ即移動して終了します。
- Enterで検索します。結果が11件以上なら「多すぎ」、0件なら「フォルダが見つかりません」と表示し、入力に戻ります。
- 結果は名前順で最大10件表示します。上下キーで選んでEnter、または項目をシングルクリックすると、あふの指定側を移動して終了します。
- 数字キー1～9で対応する候補を選べます。0は10件目です。テンキーにも対応します。
- Escape、またはウィンドウの閉じるボタンでキャンセルします。

検索文字が空の場合、Enterを押しても検索しません。候補が1件でも結果リストを表示し、選択を待ちます。

### AFXW.EXEと設定の保存

AFXW.EXEは`-afxw`の指定、保存済みパス、`findCD.exe`と同じフォルダの順に確認します。見つからなければファイル選択ダイアログを表示します。明示的に指定したパスが無効な場合はエラーを表示します。

AFXW.EXEのパスとL／R設定は、ユーザーごとに`HKEY_CURRENT_USER\Software\bry-ful\findCD`へ保存します。保存先のAFXW.EXEを移動した場合、`-afxw`で新しいパスを指定できます。
