# cdaf

指定フォルダ直下のサブフォルダを部分一致で検索し、あふｗ（`AFXW.EXE`）の左／右ウィンドウで開くコマンドラインユーティリティです。

## 動作環境

Windows x64、あふｗ（`AFXW.EXE`）。

## 機能

- 検索は指定ディレクトリの直下サブフォルダのみ（再帰しません）。
- 大文字・小文字を区別せず部分一致検索。
- 最大 9 件まで表示。10 件以上検出すると "多すぎ" と表示して終了。
- 一覧から番号（1～9）を押すと、`cdaf.def` で指定したファイラー、または実行ファイルと同じフォルダの `AFXW.EXE` を起動して該当フォルダを左右どちらかのウインドウで開く。

## 使い方

- `-l` / `-L` / `/l` / `/L` : AFXW の左ウインドウを指定
- `-r` / `-R` / `/r` / `/R` : AFXW の右ウインドウを指定

例:

- `cdaf -l` （検索文字列を対話入力）
- `cdaf -r abc` （カレント直下で "abc" を含むフォルダを検索）
- `cdaf -l abc D:\Work` （`D:\Work` の直下を検索）

実行時は候補一覧が表示され、`1`～`9` を押すと該当フォルダをファイラーで開きます。`0` または `Esc` で終了。
候補が1件の場合は選択を待たずに移動します。検索先パスを省略した場合はカレントディレクトリを検索します。

## Menu.txt での使い方
Afxのメニュー指定でこんな感じに指定しておくと便利です。
```
"cdaf L" "C:\Bin\afx\cdaf" -l
"cdaf R" "C:\Bin\afx\cdaf" -r
```

## `cdaf.def` の仕様

実行ファイルと同じディレクトリに `cdaf.def` を置くと、1 行目で使用するファイラー実行ファイルのパスを指定できます。

- UTF-8（BOM 可）または ANSI に対応。
- 行頭末尾の空白・改行・引用符は除去されます。
- 指定が無い、または無効な場合は同じフォルダの`AFXW.EXE` を探します。

## トラブルシューティング

- ファイラーが見つからない／起動できない場合は `cdaf.def` を確認するか、`afw.exe` / `AFXW.EXE` を `cdaf.exe` と同じフォルダへ配置してください。
